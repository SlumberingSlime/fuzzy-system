# fuzzy-system

静态测试页。下面的链接都指向 GitHub Pages，打开的是可操作的页面。

## special pages for CDP

[popup-integrate](https://slumberingslime.github.io/fuzzy-system/popup-integrate.html)

页面加载 5 秒后自动 `window.open`。另有按钮打开站点、展开隐藏文本。弹窗出现时看 CSS 旋转和 GIF 是否还在动。

[loop-and-alert](https://slumberingslime.github.io/fuzzy-system/loop-and-alert.html)

三个按钮：展开特殊隐藏文本后进入死循环，展开普通隐藏文本只显示文本，展开警告文本后立刻 `alert`。主线程被占住后看 CSS 旋转和 GIF 是否还在动。点过死循环需要关掉这个标签页。


## upload

[txt-upload-test](https://slumberingslime.github.io/fuzzy-system/txt-upload-test.html)

只接受 `.txt`。页面在文件框的 `change` 里读取内容并显示正文。
